# awesome-debian

Build a custom Debian OS image for your org with GitHub Actions and
[debos](https://github.com/go-debos/debos) — no Go code, no infra to run
yourself.

- **[debos-custom-os](https://github.com/awesome-debian/debos-custom-os)** — start here. Fork it, edit `recipe.yaml`, push.
- **[debos-build-action](https://github.com/awesome-debian/debos-build-action)** — the reusable Action doing the actual build.
- **[awesome-debian](https://github.com/awesome-debian/awesome-debian)** — curated tools + a directory of real-world recipes.
